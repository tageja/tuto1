# Google Authentication Setup for Mobile App

## Overview

The mobile app now supports Google Sign-In using Firebase Auth and Expo's auth session.

## Required Environment Variables

Add these to your `.env` file in the root directory:

```env
# Google OAuth Client IDs (get from Firebase Console)
EXPO_PUBLIC_GOOGLE_WEB_CLIENT_ID=your-web-client-id.apps.googleusercontent.com
EXPO_PUBLIC_GOOGLE_IOS_CLIENT_ID=your-ios-client-id.apps.googleusercontent.com
EXPO_PUBLIC_GOOGLE_ANDROID_CLIENT_ID=your-android-client-id.apps.googleusercontent.com
EXPO_PUBLIC_GOOGLE_EXPO_CLIENT_ID=your-expo-client-id.apps.googleusercontent.com
```

## Where to Get Client IDs

### 1. Firebase Console

1. Go to [Firebase Console](https://console.firebase.google.com/)
2. Select your project (`tuto1-73fc4`)
3. Go to **Authentication** > **Sign-in method**
4. Enable **Google** sign-in provider
5. Copy the **Web client ID**

### 2. Google Cloud Console

1. Go to [Google Cloud Console](https://console.cloud.google.com/)
2. Select your Firebase project
3. Go to **APIs & Services** > **Credentials**
4. You should see multiple OAuth 2.0 Client IDs:
   - **Web client** (auto-generated by Firebase)
   - **iOS client** (create if needed)
   - **Android client** (create if needed)

### 3. Create iOS Client ID

1. Click **+ CREATE CREDENTIALS** > **OAuth 2.0 Client ID**
2. Application type: **iOS**
3. Bundle ID: Get from `app.json` → `expo.ios.bundleIdentifier`
4. Click **CREATE**
5. Copy the Client ID

### 4. Create Android Client ID

1. Click **+ CREATE CREDENTIALS** > **OAuth 2.0 Client ID**
2. Application type: **Android**
3. Package name: Get from `app.json` → `expo.android.package`
4. SHA-1: Run `keytool -list -v -keystore ~/.android/debug.keystore -alias androiddebugkey -storepass android -keypass android`
5. Click **CREATE**
6. Copy the Client ID

## Current Setup

The mobile app is configured to use Google Sign-In with Firebase Auth:

- **Authentication**: Firebase Auth (same as web dashboard)
- **Flow**: Google OAuth → Firebase credential → User data → Navigation to Home
- **Fallback**: If Google auth not configured, shows helpful message

## Testing

**Without Google OAuth configured:**
- App will show a message: "Google Sign-In configuration needed"
- Users can still sign in with email/password

**With Google OAuth configured:**
- Click "Continue with Google"
- Opens Google sign-in in browser
- After success, redirects back to app
- User is logged in and navigates to RoleSelection

## Implementation Details

**File**: `src/screens/AuthUnifiedScreen.tsx`

**Uses**:
- `expo-auth-session` - OAuth flow handling
- `expo-web-browser` - Opens browser for OAuth
- Firebase `signInWithCredential` - Converts Google token to Firebase auth
