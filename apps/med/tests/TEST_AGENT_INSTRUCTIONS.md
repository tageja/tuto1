## Daily workflow (human)

```bash
cd apps/med

# fastest sanity check (~30s)
npm run test:smoke

# all 17 nurse-reported bugs (~3-5 min)
npm run test:regression

# interactive UI mode — see tests run live, debug failures
npm run test:e2e:ui

# regenerate the coverage matrix after adding tests
npm run test:coverage

# open the last HTML report
npm run test:report
```

## Workflow (Cursor agent loop)

```
/qa-loop module-2

  → /qa-explore module-2          (act like a new user, write findings)
  → /qa-codify module-2           (turn findings into regression specs)
  → npm run test:e2e --grep @module-2
  → /qa-triage                    (classify failures)
  → /qa-fix bug-N (repeat)        (minimal fix per bug)
  → npm run test:e2e              (full sweep — no new regressions)
  → close module-2, advance to module-3
```

Read each command file in `.cursor/commands/` for the exact contract.


2. **Create `apps/med/.env.local`** with at minimum:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=https://fkjeggdxqifqqwhuqpgm.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=<anon-key>
   SUPABASE_SERVICE_ROLE_KEY=<service-role-key>   # needed for data tests (bugs 12-14, 16, 17)
   NEXT_PUBLIC_AUTH_DISABLED=false
   NEXT_PUBLIC_SITE_URL=http://localhost:3001
   NEXT_PUBLIC_APP_URL=http://localhost:3001
   ```
   Pull from Vercel: `cd apps/med && vercel env pull --environment=preview`
   then restore the two local URLs above (Vercel overwrites them to production values).

3. **Verify smoke**:
   ```bash
   npm run test:smoke
   ```
   Should produce 7 green tests + an HTML report at `tests/reports/html/`.

## CI

`.github/workflows/e2e.yml` runs:

- **smoke** as a required PR gate (~3 min)
- **regression** as advisory for the first 14 days (`continue-on-error: true`)

After 14 days of green regression runs, flip `continue-on-error: false` and
regression becomes a required gate.
