# Frontend Rules

- Use functional components with hooks only.
- Keep components < 200 lines; split when larger.
- Forms: `react-hook-form` + `yup`.
- Navigation: React Navigation v6 or `expo-router`.
- Styling: NativeWind utilities; avoid inline styles where tokens exist.
- Icons: MaterialIcons only (24 nav, 20 inline).
- Caching: React Query for remote data; set TTL.
- Accessibility: labels, contrast, and 44x44 touch targets.
